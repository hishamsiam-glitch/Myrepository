# Privacy Policy — Scientific Calculator

_Last updated: 2026-08-14_

Scientific Calculator ("the app") is developed by Hisham Siam.

## Data collection

The app does **not** collect, store, transmit, or share any personal data
or usage data. Specifically, the app:

- Requests no device permissions (no camera, location, contacts, storage,
  network, etc.).
- Makes no network requests. All calculations happen entirely on your
  device.
- Uses no analytics, advertising, or crash-reporting SDKs.
- Does not create user accounts and has no backend server.
- Stores nothing beyond normal, in-memory app state that is cleared when
  the app is closed.

## Children's privacy

Because the app collects no data of any kind, it is safe for use by
audiences of any age, including children.

## Changes to this policy

If this policy ever changes (for example, if a future version adds an
optional feature that uses data), this document will be updated and the
"Last updated" date above will change accordingly.
